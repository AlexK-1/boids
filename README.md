# Boids

A [boid](https://en.wikipedia.org/wiki/Boids) simulation writen in C and Raylib.

## Contol
* Key `Space` – Pause
* Key `S` – Show the boid's field of view
* Key `C` – Make boids avoiding mouse
* Keys `+`, `-` and mouse scrolling – Zoom
* Hold left click – Camera move

## Build
```sh
cc main.c -o boids -lraylib -O2
```
